# Pooki Theme Architecture

## Frontend
- Build Tool: Vite
- CSS Framework: Tailwind CSS
- JS Framework: Alpine.js

## Backend
- Language: PHP 8.4
- Platform: Native WordPress (WooCommerce compatible)
- Architecture: SOLID principles, Component-based design
